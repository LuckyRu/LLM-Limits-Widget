# ADR 0001: Начальный scope проекта

Дата: 2026-08-12  
Статус: принято для discovery

## Решение

Проект начинаем как Windows 11 Widget для личного использования с одним личным аккаунтом ChatGPT и одним личным аккаунтом Claude. В первой версии исследуем и показываем статус доступности, оставшийся лимит там, где он надёжно наблюдаем, и время до соответствующего сброса.

## Почему

- Пользовательский сценарий требует быстрого статуса рядом с рабочим столом.
- Правые элементы панели задач Windows 11 — это область уведомлений/system tray, а не произвольный встроенный toolbar.
- Лимиты у сервисов неоднородны, поэтому модель данных должна поддерживать несколько окон и состояние неопределённости.
- Техническая доступность usage-данных пока не подтверждена и должна быть gate перед реализацией.
- Team, Enterprise, Business, Edu и другие рабочие пространства исключены из начального scope.

## Последствия

- Не фиксируемся на одном универсальном проценте или количестве сообщений.
- Считаем честность и свежесть данных частью основного UX.
- Не храним пароли и не строим MVP на неустойчивом обходе защитных механизмов.
- До реализации проводим интервью и feasibility spike.
- Модель данных и UX оптимизируем под два личных аккаунта, а не под администрирование пользователей или команд.

## Альтернативы, которые пока отклонены

- Отдельное полноценное desktop-приложение без tray-режима: слишком далеко от сценария быстрого взгляда.
- Только ручной счётчик сообщений: будет неточным из-за разных моделей, контекста и окон лимитов.
- Автоматическая покупка кредитов: выходит за scope и несёт финансовый риск.
