# ADR 0002: Целевая зона и Windows Widgets-платформа

Дата: 2026-08-12  
Статус: принято для discovery

## Решение

Целевой продуктовый образ — компактный Windows Widget в стиле погодного статуса на панели задач. Технический baseline — сторонний Widget в Widgets Board; постоянное inline-представление в строке taskbar проверяется отдельно.

## Почему

- Пользователь хочет видеть статус как системную glanceable-информацию, без запуска полноценного приложения.
- В этой зоне достаточно горизонтального пространства для двух коротких статусов ChatGPT и Claude.
- Постоянная видимость лучше соответствует задаче «одним взглядом понять, можно ли начинать работу».

## UX-требование

В нормальном состоянии виджет должен занимать минимум места и показывать только короткий статус. Подробности — по наведению, клику или раскрытию, без необходимости открывать полноценное приложение.

## Техническое ограничение

Скриншоты фиксируют желаемое поведение, но официальная документация Microsoft описывает сторонние Widgets как карточки в Widgets Board. Она не подтверждает произвольное встраивание стороннего контента в строку taskbar рядом с погодой. До реализации нужно проверить inline-гипотезу. Tray companion сохраняем как fallback, но не считаем заменой Windows Widget.
