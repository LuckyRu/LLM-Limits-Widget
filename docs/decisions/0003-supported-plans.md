# ADR 0003: Поддерживаемые планы первого релиза

Дата: 2026-08-12  
Статус: принято для discovery

## Решение

Первый релиз ориентирован на личные планы ChatGPT Plus, ChatGPT Pro и Claude Pro.

## Не входит

- ChatGPT Team, Business, Enterprise, Edu и workspace usage.
- Claude Team и Enterprise.
- OpenAI API и Anthropic API usage как замена subscription usage.

## Почему

Продукт предназначен для личного использования. Ограничение scope уменьшает сложность UX, авторизации и модели данных, но не снимает главный риск: consumer subscription usage может быть доступен только внутри собственных интерфейсов сервисов.
